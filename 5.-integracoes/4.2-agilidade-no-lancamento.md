# 4.3 Gerando desenhos

### Gerando desenhos com o Nodes

O Nodes também pode ser usado para gerar desenhos dentro do Eberick. Para isso, existe um conjunto de nós voltado à criação de elementos gráficos, como linhas, círculos, retângulos, arcos, hachuras, cotas e textos.

### O papel do ponto

O nó mais importante dessa lógica é o Ponto.

Ele define a coordenada que será usada como referência no desenho. Em outras palavras, é a partir dos pontos que os demais elementos são posicionados e construídos.

Os outros nós de desenho usam esses pontos como base.

Uma Linha, por exemplo, pode ser criada a partir de dois pontos. Um Retângulo, uma Poligonal ou um Arco também dependem de coordenadas para definir sua forma. O mesmo vale para elementos como Cota e Texto CAD, que precisam de uma posição para serem inseridos.

Por isso, mesmo quando o resultado final é uma geometria mais elaborada, a base da construção continua girando em torno dos pontos.

### Onde o desenho é criado

O local onde o desenho será gerado depende do que estiver aberto no Eberick no momento da execução.

Se nenhuma janela estiver aberta, o desenho será criado em uma nova janela.\
Se já existir uma janela aberta, o desenho será realizado nessa janela ativa.

{% hint style="info" %}
Os nós de desenho não executam suas ações automaticamente como acontece em alguns outros fluxos do Nodes. Para gerar o desenho no Eberick, é necessário acionar o botão **Executar**.
{% endhint %}
