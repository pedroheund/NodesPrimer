# 5.3 Pacotes

### O que são pacotes

Além do uso básico do Python, o Nodes também permite trabalhar com pacotes. De forma simples, pacotes são conjuntos prontos de funcionalidades que podem ser adicionados ao ambiente para expandir o que você consegue fazer com código.

Isso é importante porque evita que você precise escrever tudo do zero. Em muitos casos, já existem soluções prontas para diferentes tipos de tarefa, e os pacotes permitem aproveitar esses recursos dentro das suas rotinas.

### Instalando pacotes no Nodes

No menu do Nodes, existe uma opção para instalar pacotes. Com isso, o ambiente passa a ganhar novas possibilidades de uso, ampliando bastante o alcance do nó Python.

Na prática, isso permite adicionar novos recursos ao ambiente e aproveitar funcionalidades que vão além do código mais básico escrito manualmente dentro do nó.

### Por que isso amplia tanto o potencial

Esse é um dos pontos mais fortes de usar Python no Nodes. Como a linguagem tem uma comunidade enorme, existe uma quantidade muito grande de pacotes produzidos para diferentes finalidades.

Isso faz com que o Nodes não fique limitado apenas ao fluxo visual ou ao código mais básico, mas também possa aproveitar todo esse ecossistema construído em torno da linguagem. Na prática, você consegue reaproveitar soluções já existentes, acelerar o desenvolvimento das rotinas e acessar recursos mais avançados sem precisar implementar tudo manualmente.

### Expansão

O nó Python já abre muitas possibilidades por permitir escrever lógica textual dentro do fluxo. Com pacotes, esse alcance fica ainda maior.

Ou seja: Python amplia a flexibilidade do Nodes, e os pacotes ampliam ainda mais o que pode ser construído a partir dele.
