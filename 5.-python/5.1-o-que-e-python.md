# 5.1 O que é Python?

### Uma outra forma de montar lógica

Python é uma linguagem de programação textual. Isso significa que, em vez de montar a lógica conectando blocos visuais, você escreve instruções em texto para dizer ao computador o que ele deve fazer.

Para quem nunca programou, a ideia principal é simples: no Nodes, você pode construir uma rotina ligando nós; com Python, essa mesma lógica pode ser escrita em código. No fim, os dois caminhos levam ao mesmo objetivo: receber dados, processar esses dados e gerar um resultado.

### Por que usar Python

Python costuma ser uma boa porta de entrada para quem está começando porque sua escrita é mais direta e organizada do que a de muitas outras linguagens. Por isso, ele é bastante usado tanto por quem está aprendendo quanto por quem já programa há mais tempo.

No contexto do Nodes, o Python passa a fazer sentido quando a rotina começa a ficar mais extensa no fluxo visual, quando você quer concentrar várias regras em um único ponto ou quando precisa tratar dados de uma forma mais personalizada. Nesses casos, escrever a lógica em texto pode deixar a solução mais compacta e mais flexível.

### Python e Nodes trabalhando juntos

Usar Python no Nodes não significa substituir o fluxo visual. Na prática, os dois se complementam. O Nodes continua sendo uma forma muito clara de montar a lógica, e o Python entra como um recurso adicional para situações em que escrever o passo a passo em código faz mais sentido.

Outro ponto importante é que Python é uma linguagem muito difundida. Isso significa que existe muito material de aprendizado, muitos exemplos prontos e uma comunidade enorme produzindo conteúdo e soluções. Dentro do Nodes, isso amplia bastante as possibilidades de uso.
