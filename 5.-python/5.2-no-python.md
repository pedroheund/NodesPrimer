# 5.2 Nó Python

### Como o nó funciona

No Nodes, existe um nó específico para trabalhar com Python, dentro da seção Programação.

Ao abrir esse nó, aparece uma janela própria para edição. Nela, existe um campo de Entradas, um campo de Saídas e uma área central para escrever o código. A janela também apresenta a opção Executar automaticamente e um campo para definir o Tempo máximo para execução.

A lógica do nó continua sendo a mesma dos outros nós do fluxo: algo entra, algo é processado e algo sai. A diferença é que, nesse caso, o processamento não é montado com conexões visuais internas, mas escrito em Python dentro do editor.

### Entradas, saídas e código

As entradas são os valores que chegam ao nó vindos da rotina. As saídas são os resultados que o código devolve para continuar o fluxo. Já a área central é o espaço em que você escreve a lógica que transforma as entradas nas saídas.

Isso faz com que o nó Python funcione como uma pequena área de programação dentro do próprio Nodes, permitindo criar trechos de lógica textual sem sair da rotina visual.

### Um primeiro exemplo

Um bom começo é usar o nó Python para fazer uma conta simples. Imagine duas entradas chamadas a e b, e uma saída chamada c. Nesse caso, o código pode ser:

```python
c = a + b
```

Aqui, o funcionamento é direto: os valores de a e b entram no nó, o código realiza a soma e o resultado sai por c.

Depois disso, você pode avançar para expressões um pouco maiores, como:

```python
c = (a * b) + 10
```

ou

```python
c = (a + b) / 2
```

Esses primeiros testes são úteis porque mostram que o nó Python pode começar de forma simples, sem bibliotecas externas e sem exigir nada muito avançado.
