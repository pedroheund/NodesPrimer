# 7. Glossário

#### Automação

Automação é quando uma tarefa deixa de ser feita manualmente, passo a passo, e passa a ser executada por uma rotina montada no Nodes.

#### Barra

No modelo do pórtico do Eberick, a barra é o trecho linear que conecta dois nós. É nesse nível que os esforços são calculados.

#### Booleano

É um tipo de dado que possui apenas dois estados possíveis: verdadeiro ou falso.

#### Código textual

É a lógica escrita em texto, como acontece no Python. Diferente do fluxo visual, aqui as instruções são digitadas diretamente.

#### Conexão

É a ligação entre nós dentro da rotina. As conexões mostram como os dados passam de uma etapa para outra.

#### Dado

É qualquer informação que circula no fluxo, como números, textos, listas, elementos selecionados ou resultados obtidos do modelo.

#### Desenho

No contexto do Nodes, desenho é a geração de elementos gráficos dentro do Eberick, como pontos, linhas, círculos, retângulos, cotas, hachuras e textos.

#### Eberick

É a solução com a qual o Nodes atualmente se integra no primer, permitindo acessar informações do modelo, consultar esforços e gerar desenhos.

#### Elemento

É o objeto do projeto com o qual a rotina trabalha, como uma viga, um pilar, uma laje ou outro componente selecionado no modelo.

#### Entrada

É o valor que chega a um nó para que ele possa executar sua função.

#### Esforço ao longo da barra

É o esforço consultado no trecho da barra, e não apenas em suas extremidades. Exemplos apresentados no primer são axial máximo, fletor máximo e torsor.

#### Esforço nodal

É o esforço obtido nas extremidades da barra, ou seja, no ponto inicial ou final do trecho analisado.

#### Fluxo

É o caminho que os dados percorrem dentro da rotina, passando de nó em nó até gerar um resultado.

#### IFC

É o conjunto de propriedades que pode ser associado aos elementos e acessado no Nodes para uso dentro das rotinas.

#### Iteração

É o processo de repetir uma ação sobre vários itens de uma lista.

#### Lista

É uma coleção de itens organizados dentro de uma mesma estrutura.

#### Lista aninhada

É uma lista que contém outras listas dentro dela. Ela é útil quando os dados precisam continuar organizados em grupos.

#### Lógica

É a sequência de decisões, operações e relações que fazem a rotina funcionar.

#### Nó

É cada bloco da rotina. Cada nó representa uma ação, um dado ou uma transformação dentro do fluxo.

#### Nó Python

É o nó que permite escrever código Python dentro do Nodes, usando entradas, saídas e uma área de edição de código.

#### Pacote

É um conjunto pronto de funcionalidades que pode ser instalado para ampliar o que pode ser feito com Python no Nodes.

#### Programação visual

É a forma de montar lógica conectando blocos visuais em vez de escrever código textual.

#### Propriedade personalizada

É uma informação criada especificamente para um elemento e que também pode ser lida no Nodes como dado de entrada da rotina.

#### Propriedade IFC

É uma informação associada ao elemento e disponível para leitura dentro da rotina.

#### Ponto

É o nó base para construção de desenhos. Ele define a coordenada usada como referência para posicionar os demais elementos gráficos.

#### Pórtico

É o modelo analítico do Eberick formado por barras e nós, usado como base para a análise estrutural.

#### Rotina

É o conjunto organizado de nós, conexões e lógica montado para resolver um problema, automatizar uma tarefa ou gerar um resultado.

#### Saída

É o resultado devolvido por um nó depois que ele processa as entradas recebidas.

#### Sintaxe

É a forma correta de escrever o código em uma linguagem textual, como Python.

#### Visual x textual

No Nodes, a lógica pode ser construída visualmente com nós ou, em alguns casos, escrita em texto com Python. Os dois caminhos servem para organizar entradas, processamento e saídas.
